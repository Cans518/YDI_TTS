提供 Windows、Linux 和 macOS 发布包，源码使用 GPL-3.0-only。

- Windows x86_64：单文件便携 EXE，无需另带 Qt 运行库。
- Linux x86_64：AppImage，基于 Ubuntu 22.04 构建，验证 X11 与 Wayland 启动。
- macOS 12+：分别提供 arm64 和 x86_64 DMG。采用临时签名，**未使用 Developer ID 签名、未公证**。

本版增加 Linux/macOS 明确的 GBK 编码支持、桌面入口、应用图标和原生打包流程。保留五档参数、合并音色音调、模块配置回读和三个顶部跳转入口。程序每次默认启动，不保存配置文件。

下载后可用 `SHA256SUMS` 校验文件；`release-manifest.json` 记录对应源码提交和文件摘要。Linux AppImage 需要赋予执行权限；macOS 首次打开可能需要在“系统设置 → 隐私与安全性”中确认。

验证涵盖自动化协议与界面测试、打包产物的独立启动。实际串口设备、驱动及模块固件兼容性仍需在目标机器上联调。
