本次维护版本改进串口事务的健壮性，整理代码与测试结构，并更新项目文档。

## 修复

- 拒绝空指令批次及不可读写的设备，设备释放后及时结束事务。
- 避免发送前的进度回调将旧回复误判为当前指令的确认。
- 修复参数映射和滑块范围运算在整数极值下的溢出。
- 修复按住滑块时旧动画继续播放，以及隐藏控件后悬停提示残留的问题。

## 开发与文档

- 分离协议核心、通用控件和应用层，拆分主窗口流程与视图。
- 按协议、控件和工作流整理测试，新增 6 个回归测试。
- 补充设备所有权、异步回调、参数确认时机等关键注释。
- 新增可预览的本地产物清理脚本及开发指南。
- 更新 README 的应用图标、技术徽章、运行截图和上手说明。

## 下载

- **Windows x86_64**：单文件便携 EXE，下载后直接运行。
- **Linux x86_64**：AppImage，适用于 Ubuntu 22.04 / glibc 2.35 或更新系统。
- **macOS 12+**：分别提供 arm64、x86_64 DMG，采用临时签名，未进行 Developer ID 签名或公证。

`SHA256SUMS` 提供文件校验和，`release-manifest.json` 记录源码提交与发布文件摘要。测试程序不包含在应用发布包中。
