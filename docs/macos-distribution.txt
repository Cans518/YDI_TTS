长风 TTS macOS 版

将 YDI_TTS.app 拖入 Applications 后启动。

此版本使用本地临时签名，尚未使用 Developer ID 签名或提交公证。
如果系统阻止首次打开，请先确认文件来自 Cans518/YDI_TTS 的正式发布页，
核对 SHA256SUMS，再按 macOS“系统设置 → 隐私与安全性”中的提示允许打开。

程序不保存配置，每次启动恢复默认值。使用前连接 USB 串口设备，
并确保系统已识别对应串口。参数回读与播报需要连接真实模块验收。

项目与源码：https://github.com/Cans518/YDI_TTS
源码许可证：GPL-3.0-only；内置资源与依赖遵循各自随附许可。
